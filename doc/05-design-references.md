
# Design References

The goal is inspiration, never imitation.

Each reference should inspire one specific aspect of the website.

No page or section should look like a direct copy of another event.

---

## Rahue Classic

https://www.rahueclassic.com/

Why we like it:

- Premium aesthetic.
- Dark interface.
- Excellent typography hierarchy.
- Strong hero section.
- Beautiful map presentation.
- Clean spacing.
- High-quality photography.

Avoid:

- Copying layouts.
- Copying color palette.
- Copying section order.

## Existing Rally Website

https://rallydelvientoalosandes.com/

Purpose:

- Preserve existing information.
- Improve every aspect of the visual experience.
- Keep historical content when appropriate.

Known issues to solve:

- Generic layout.
- Weak visual hierarchy.
- Map section.
- Hero video.
- Mobile experience.

# Things to Avoid

Do not reproduce:

- Generic event landing pages.
- Heavy card-based layouts.
- Excessive gradients.
- Generic mountain illustrations.
- White backgrounds.
- Bootstrap aesthetics.
- Material Design appearance.
- Overly corporate interfaces.
