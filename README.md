# Rally del Viento a los Andes v2

Complete redesign of the official Rally del Viento a los Andes website.

## Goals

- Inspire before informing.
- Sell an experience, not a race.
- Showcase Patagonia and the mountain environment.
- Responsive.
- High performance.
- SEO optimized.
- Interactive GPX maps.
- Historical results.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- MapLibre GL

## Development

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The development server will be available at:

```text
http://localhost:5173/
```

### Build for production

```bash
npm run build
```

This generates the production-ready files in the `dist/` directory.

### Preview the production build

```bash
npm run preview
```

This serves the production build locally for testing before deployment.
